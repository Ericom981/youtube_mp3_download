# yt-downloader

## Requirements
- Node 18+
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) on PATH (`pip install -U yt-dlp`)
- [ffmpeg](https://ffmpeg.org) on PATH (needed for merging video+audio and MP3)

## Run
    npm install
    npm start
    # open http://localhost:3000

Keep yt-dlp updated (`pip install -U yt-dlp`); YouTube changes often.
Only download content you own or have permission to save.
